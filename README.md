# Passive Voice with Modal Verbs

Интерактивный одностраничный курс по пассивному залогу с модальными глаголами (уровень A2–B2).
Один файл, ноль зависимостей, ноль внешних запросов — открывается двойным кликом или с любого статического хостинга.

**Живая версия:** https://timaxmetov.github.io/passive-voice-modals/

## Что внутри

| Блок | Что делает |
|---|---|
| Пять историй | Теория как байки: база `modal + be + V3`, отрицание, вопросы, длительный и перфектный пассивный инфинитив |
| Конструктор пассива | Многоступенчатая диаграмма на 5 ступеней, собирает предложение вживую с русским подстрочником |
| Тренажёр | 4 режима, 22 задания: выбор формы, сборка из блоков, актив → пассив, поиск верного варианта |
| Финальный тест | 8 вопросов с обратным отсчётом на 5 минут и разбором результата |
| Видеоуроки | 6 проверенных уроков с YouTube, обложки вшиты в страницу как data-URI |
| Задание с ключом | 8 предложений из учебника, ключ учителя открывается по кнопке |

## Функции

- **Прогресс-трекер** — XP, кольцевой индикатор, 8 блоков, сохранение в `localStorage`
- **Озвучка** — Web Speech API: примеры по-английски, истории по-русски, регулировка скорости
- **Тёмная и светлая тема** — по системной настройке плюс ручной переключатель
- **Mobile-first** — вертикальная раскладка на телефоне, горизонтальная диаграмма на десктопе
- **`prefers-reduced-motion`** — все анимации отключаются

## Структура

```
index.html   единственный файл: разметка, стили, скрипты и обложки видео
```

## Локальный запуск

Скачать `index.html` и открыть в браузере. Сервер не нужен.
